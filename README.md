# ☁️ Cloud File Upload App

A simple and efficient cloud-based file upload and sharing web application built using React and Supabase.

---

## 🚀 Features

- 📤 Upload files to cloud storage  
- 🔗 Generate public URLs for each file  
- 📂 View and access uploaded files  
- 🌐 Access files from anywhere  
- ⚡ Fast and simple UI  

---

## 🛠️ Tech Stack

- Frontend: React.js  
- Backend: Supabase (Storage)  
- Deployment: Vercel  

---

## ☁️ Cloud Features Used

- Cloud Storage (Supabase Storage)  
- Public File Hosting  
- Remote Accessibility  
- Scalability
